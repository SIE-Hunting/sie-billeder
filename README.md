# SIE-billeder

Produktbilleder fra SIE's leverandører til webshoppen. Webshoppen henter billederne via deres offentlige adresse.

Regler:
* Kun leverandørernes egne produktbilleder, som de selv har offentliggjort. Aldrig kunde- eller ordredata, priser eller interne dokumenter.
* Én mappe pr. leverandør, fx `zeiss/`.
* Billeder lægges på grenen main, så adressen er fast. Billeder, der bruges på webshoppen, slettes ikke.
